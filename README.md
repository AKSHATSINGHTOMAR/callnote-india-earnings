# Callnote — Indian earnings calls

A static call player that highlights transcript words alongside the recording.

## Included calls

- Yash Highvoltage Limited — H1 FY27 earnings call, 21 October 2026
- SG Finserve Limited — Q2 and H1 FY27 earnings call, 16 October 2026

The player uses AAC copies of the recordings for browser compatibility and includes the official transcript PDFs. The interactive transcript preserves the company PDF wording. Timing is recognition-based; where speech and PDF wording differ, timing is interpolated. The page reports the approximate share for each call.
